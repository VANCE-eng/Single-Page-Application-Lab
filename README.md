WORDLY DICTIONARY is a simple dictionary web app. It is used to search for a word to see its meaning, pronunciation, and synonyms, and save your favorite words for later.

FEATURES

Look up definitions, pronunciation, and synonyms.
Hear the word spoken aloud (Listen button).
Save and unsave words; saved words are kept in your browser (localStorage).
Friendly error messages for empty searches, unknown words, and network problems.
BUILT WITH

HTML, CSS, and JavaScript
TailwindCSS
Datamuse API for word data
Jest for testing
GETTING STARTED Download or clone this project. Open index.html in your browser. Type a word and click Search.

RUNNING TESTS bash npm install --save-dev jest jest-environment-jsdom npm test

PROJECT STRUCTURE

index.html # Page layout
style.css # Custom styles
index.js # App logic
index.test.js # Jest tests
